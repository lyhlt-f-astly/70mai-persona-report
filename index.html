DATA INSIGHT

核心痛点

P0APP 连接体验差
连接繁琐、速度慢、频繁断连、熄火后连接丢失。东南亚用户NPS最大拖累因素
→ WiFi连接一键化 + 后台自动重连 + 连接状态可视化
P0固件-App连接兼容性
不同固件版本WiFi模块稳定性差异大，连接后数据无法预览或下载失败
→ 固件-App版本兼容矩阵 + 自动检测 + 回退机制
P1多语言翻译质量参差
6种语言翻译质量不一致，部分语言存在机器翻译痕迹，影响用户信任感和功能理解
→ 母语级翻译校对 + UI文案一致性审核
P1夜视效果不满意
夜间录制画质不清晰，App端回放噪点多，与宣传的"星光夜视"效果有差距
→ App内画质增强算法 + 最佳设置推荐
P2ADAS功能实用性低
误报率高、灵敏度不可调，多数用户关闭此功能
→ ADAS灵敏度3档可调 + 场景化推荐
P2存储管理不便
SD卡满后无法智能覆盖，缺乏存储空间预警
→ 智能循环录制 + 空间预警 + 重要视频锁定

小米品牌关联度分析
小米关联度高 — 品牌混淆风险
东南亚部分用户误认为70mai是小米子品牌或小米生态链产品。这种关联源于70mai早期通过小米有品众筹出海的历史。随着小米品牌在东南亚的扩张（手机/IoT/汽车），品牌混淆可能进一步加深
关联带来的双刃剑效应
短期：小米品牌背书有助于初期获客和信任建立。长期：品牌独立性缺失，一旦小米品牌出现负面事件或被竞品对标，70mai将被动受损。且小米SU7上市后车机互联需求激增，用户可能期望70mai与小米生态打通
UX设计建议：弱化关联，强化独立
App内去除任何小米相关视觉元素；强化"70mai"独立品牌标识；在品牌故事/关于我们页面明确70mai的独立品牌定位；通过App体验品质（而非品牌关联）建立用户信任

UX 设计重点结论

东南亚市场 · UX设计六大重点
01 · 基础设施
WiFi连接稳定性是NPS最大拖累，一键连接+后台自动重连是用户体验地基
影响所有功能体验，不解决则其他优化无效
02 · 本地化
6语言母语级翻译是Onboarding前提，月新增29.2万用户覆盖6国
直接影响功能发现率和新用户留存
03 · 品牌独立
弱化小米品牌关联，强化70mai独立品牌认知和品质感
App内去除小米视觉元素，强化独立品牌故事
04 · 夜视体验
东南亚夜间驾驶场景普遍，App端画质增强+最佳设置推荐可弥合期望差
夜视是核心购买决策因素之一
05 · ADAS实用化
灵敏度3档可调+误报减少，让ADAS从"关闭"变为"有用"
用户有兴趣但关闭率高，关键在可调性
06 · 竞争差异化
DDPAI产品重叠度最高，App体验和品牌差异化是突围核心方向
东南亚竞品矩阵中DDPAI是最直接对手

对70迈的建议

UI/UE🌏 东南亚专属
6语言本地化是App体验基础
东南亚覆盖马来语/泰语/越南语/印尼语/英语/印地语6种语言。当前机器翻译痕迹严重影响用户信任感和功能发现率。建议投入母语级翻译校对团队，建立UI文案多语言一致性审核流程
→ 影响月新增29.2万用户的Onboarding体验和留存率
UI/UE🌏 东南亚专属
电商入口深度整合
Shopee和Lazada是东南亚双巨头电商平台，用户购买决策高度依赖电商页面信息。建议在App内整合Shopee/Lazada商品页跳转，提供平台专属优惠券入口和价格比较功能
→ 匹配东南亚"电商原住民"购买习惯，提升转化
品牌🌏 需注意
小米品牌关联需主动管理
东南亚部分用户将70mai与小米关联（源于早期小米有品众筹历史）。建议在App内去除任何小米相关视觉元素，明确70mai独立品牌身份。小米SU7上市后可能加剧关联混淆
→ 品牌独立性是长期品牌资产的基础
UI/UE🌏 东南亚专属
YouTube评测内容嵌入
YouTube评测是东南亚用户购买决策核心参考（视频消费大国）。建议在App内嵌入评测视频内容、产品对比数据和用户评价精选，减少用户跳出到外部做决策
→ 将评测驱动决策的闭环留在App内完成

核心痛点

P0App Store 评分极低（2.1/5）
北美对App体验容忍度极低，App体验是核心评价指标。当前评分严重损害品牌信任
→ App UI全面重设计，对标BlackVue交互品质
P0供电稳定性
超级电容方案推荐+断电告警+最后录像确认，"关键录像丢失"焦虑最突出
→ 供电异常预警系统 + 最后录像确认机制
P1录音法律合规
美国12个州限制车内音频录制，缺乏州法合规提示和录音开关
→ 基于GPS定位的州法合规提示 + 智能录音开关
P1证据导出流程繁琐
需要完整"事故证据链"（视频+GPS+时间戳），导出流程不够直观
→ 一键生成事故证据包 + 保险理赔报告模板
P2停车监控耗电焦虑

对70迈的建议

⚠️ 法律场景🇨🇳 中国专属
防碰瓷 — 中国行车记录仪第一刚需
"碰瓷"是中国行车记录仪第一购买动机（17%核心动机），防碰瓷功能是中国市场独有的高价值场景。建议开发AI异常行为检测系统：自动识别碰瓷行为 → 自动标记事件 → 快速回放关键片段 → 一键导出完整证据包（视频+时间+GPS+加速度数据）
→ 中国市场独特价值点，可成为70mai在中国市场的核心差异化标签
UI/UE🇨🇳 中国专属
58%首购用户需要完整引导流程
超过一半中国用户是首次购买行车记录仪，对App功能缺乏认知。高级功能（ADAS/云存储/停车监控）使用率极低。建议建立完整的渐进式Onboarding流程：开箱指导 → 安装步骤 → WiFi配网 → 首次录制 → 功能发现卡片 → 使用技巧推送
→ 日均新增约3,000用户，Onboarding体验直接影响留存
UI/UE🇨🇳 中国专属
微信分享生态深度整合
朋友圈43%是最常用社交分享渠道。当前视频导出和分享流程不够便捷和美观。建议：①一键分享到微信朋友圈 ②精美"行车记录分享卡"模板 ③15s/30s短视频自动剪辑+水印导出 ④小红书种草笔记模板
→ 分享品质直接影响品牌形象和口碑传播
UI/UE🇨🇳 中国专属
新能源车机适配是趋势刚需
中国新能源车渗透率已超60%（比亚迪/特斯拉/蔚小理），车机互联需求激增。小米SU7上市后用户对车机互联的期望进一步提高。建议优先适配CarPlay/Android Auto，同时探索与比亚迪/特斯拉等新能源车企的原生车机互联方案
→ 不适配新能源车机将逐步失去中国市场增量用户
UI/UE🇨🇳 中国专属
智能客服前置分流+画质设置向导
客服满意度最低（3.91分），退货体验待优化（3.93分）。画质是32%用户第一决策因素但设置过于技术化。建议：①AI智能客服前置分流+常见问题可视化+人工客服一键转接 ②画质设置向导（场景化推荐+一键最佳画质）
→ 降本增效+提升首购用户功能发现率
品牌🇨🇳 需注意
小米关联度四大市场最高 — 品牌混淆风险最大
中国市场用户最容易将70mai与小米品牌关联（小米有品众筹历史+小米SU7车机关联+小米行车记录仪产品线直接竞争）。建议：①App内彻底去除小米关联元素 ②强化70迈销额#1的独立品牌定位 ③通过App智能化体验建立差异化品牌认知
→ 小米关联度在四大市场中最高，品牌混淆风险也最大
